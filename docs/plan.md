# 网站规划与维护说明

## 项目目标

以 Dark Minimal 模板现有 Astro 页面和暗色简约视觉为基础，呈现四川大学区块链协会的定位、活动和共建方式，提供清楚的成员招募/合作咨询入口。网站响应式、易更新，未核实的信息不作为事实展示。

## 信息架构

1. **首页 / 关于我们**：跨专业科创社团介绍；区块链、智能合约、Web3、AI-Agent 方向。
2. **我们在做什么**：技术沙龙/Workshop、项目原理研读、链上投研、论文研读、科研探索、科创赛事及开发者社群连接。
   - **认识我们的成员**：独立横向成员轮播，展示原创卡通头像、简介与可展开档案。真实成员资料尚未提供，六个位置明确标为待补充。
3. **发展规划**：学习培养体系、区块链 × AI-Agent、持续内容产出、赛事准备、科创资源及长期运转机制。
4. **寻求合作 / 共建伙伴**：可提供的青年人才、内容、校内活动和联动渠道；希望联系的高校社团、科研机构、技术团队、平台、赛事主办方与技术社群。
5. **西南高校区块链联盟**：倡议与共建计划，当前所列学校/社团为意向伙伴，不得表述为已加入或已确认合作。
6. **活动回顾**：招新、讲座、沙龙、Workshop、参赛纪实，未来附图文与讲义。
7. **学习资源中心**：入门路线、课件、项目解析、研报、备赛资料及论文清单。
8. **加入我们 / 联系**：普通成员报名与合作咨询两条独立通道。
9. **页脚**：学生自建/不代表学校立场说明，以及教学用途、非投资建议与不鼓励交易的声明。

## 内容来源与占位策略

首页及版块要点以用户提供的协会简介为准。暂未取得：协会 Logo/摄影素材、活动历史与时间地点、讲义或资源链接、正式报名表、QQ群、公众号、合作咨询方式、域名等。当前将这些内容显示为待补充状态；收集后需要由协会负责人复核准确性、隐私和素材授权，再发布。用户列出的电子科技大学、成都信息工程大学及川内高校相关社团，只作为联盟意向伙伴展示。

## 视觉与交互约束

- 使用深海军蓝背景、电光紫与亮青蓝强调色、少量玫粉环境光；主题变量集中在 `src/styles/theme.css`，参考与调色方法见 [主题配色](theme.md)。不加载未知外部图片。
- 桌面端多列卡片；移动端单列/双列适配，底部固定锚点导航保留安全区，不发生横向溢出。
- 使用语义化地标与标题层级、跳过导航链接、清晰键盘焦点、可读对比度。
- 尊重 `prefers-reduced-motion`；动画仅作装饰，核心文案与功能不依赖动画。
- 加入/合作入口未有真实 URL 前保持说明占位，不设置无效表单或伪成功反馈。

## 组件与代码复用原则

本项目遵循“优先复用、按需抽取”的原则，完整开发约束见根目录 [AGENTS.md](../AGENTS.md)，后续人工开发及 AI 修改均应遵循。

- 活动介绍复用 `ActivityCards`、shadcn Card 和 MagicCard；成员区复用 `ActivityGallery` 轮播容器，卡片与档案共用 `MemberPortrait`。静态内容优先 Astro，活动卡片仅在可见时加载 React 交互。
- 后续涉及重复卡片、按钮、区块标题等结构时，优先抽取 `src/components/ui/` 公共组件，以 props、slots 和少量变体复用。
- 复杂交互优先评估适用的成熟组件；静态展示优先使用 Astro。引入库时兼顾兼容性、可访问性、维护情况与加载体积。
- 动效优先使用已有 Motion，设计参数与交互逻辑集中维护，避免重复代码和多套同类依赖。
- 调整组件时逐步整理相关重复实现，避免无限叠加 CSS 覆盖，也避免无关的大规模重构。

## 维护入口

自建管理分支采用 Cloudflare Workers + D1 + R2。`/admin` 提供独立登录与成员、活动回顾、学习资源、联系方式四类表单，首页不增加登录入口。表单复用 shadcn Field、Input、Card、Button 等组件；前台继续复用既有展示组件和 Motion 动效。草稿与发布快照分别存储，保存草稿不改变已发布内容，修改带版本号以防止覆盖他人编辑。初始化、部署和更新操作见 [内容管理说明](cms.md)。原 Sanity 实现保留在 `feat/sanity-content-management` 分支。

主导航按页面顺序提供九个独立入口：首页、活动、成员、规划、回顾、资源、合作、联盟和加入。导航图标复用 `lucide-react` 并由 Astro 静态渲染，桌面与手机均显示。手机导航可横向滑动，当前区块的入口自动滚入可见范围；导航只改变自身横向位置，不拦截页面滚轮。

成员区与发展规划共用 `ShowcaseHeading`、`ShowcaseCard` 和紧凑区块间距。规划以六张静态 Astro 卡片呈现，桌面三列、平板两列、手机单列，复用统一 Motion 入场动效和主题变量。内容随文档自然滚动，无须点击按钮展开，窄屏不强制压入一屏。

其余区块沿用同一标题与卡片体系：活动介绍保留 `ActivityCards` / MagicCard，活动回顾为错落档案展架，资源中心为书册视觉与目录，合作展示为双向面板，联盟复用 `NetworkVisual` 节点图，加入区为两个清晰入口。所有未提供的活动资料、下载链接、二维码和合作状态继续明确占位。

整站滚动采用原生滚动与导航锚点平滑定位；`motion.ts` 集中处理标题遮罩入场、可见条目错峰入场、视口内的装饰视差、进度线与磁力角框。React 岛屿的入场放在 Astro 外层，避免在 hydration 前修改 React 管理的 DOM。手机减少视差幅度，减少动画偏好关闭装饰动画。参考并阅读了 JIEJOE 的 [007-02 滚动跟随](https://github.com/JIEJOE-WEB-Tutorial/007-02-scroll-follow)、[018 磁力光标](https://github.com/JIEJOE-WEB-Tutorial/018-magnetic-pointer) 与 [020 百叶窗](https://github.com/JIEJOE-WEB-Tutorial/020-window-blinds) 源码；依据其进度映射、目标吸附和裁剪思路适配本项目，未引入 GSAP / Lenis 或复制教程素材。

成员资料集中在 `src/data/members.ts`：填写本人确认的姓名、职责、简介、方向标签、项目经历和公开链接后，将 `placeholder` 改为 `false`。头像位于 `public/images/members/`，生成提示词与来源记录见该目录的 `ASSETS.md`。当前头像均为原创风格插图，不代表真实成员肖像。

成员轮播支持原生触摸滑动、箭头按钮和方向键/Home/End，纵向滚轮用于浏览整页。档案采用原生 `dialog`，由浏览器处理模态焦点与 Esc；关闭后恢复触发按钮焦点。头像视差、磁力角框和弹层入场集中于 `src/scripts/motion.ts`，尊重减少动画偏好。JIEJOE 教程仅用于交互原理参考，没有引入其素材或额外动画库。

页面内容分布与文件映射见根目录 README 的“内容维护”。维护者更新内容后应同步检查对应导航锚点、窄屏表现、资源链接及文案事实依据。活动和资源条目增加时可再拆分为独立数据文件，以便非开发者维护；当前阶段保持 Astro 组件中的轻量内容数组。

## 验收清单

- [ ] `npm run build`（包含 `astro check`）成功。
- [ ] 首页所有用户给定主题均有对应内容；页脚声明和 `©2026 四川大学区块链协会` 正确。
- [ ] 不含模板个人姓名、个人社交链接、占位项目、Spotify/Firebase 点赞和 Formspree 假联系表单。
- [ ] 导航锚点都指向存在的区块；桌面及移动导航可键盘操作。
- [ ] 320px 窄屏、平板、桌面无横向滚动或卡片溢出；文本易读、焦点可见。
- [ ] reduced-motion 偏好下禁用非必要动画/平滑滚动。
- [ ] 招新、联系、活动、资料及合作信息没有被伪造；联盟仍标注为倡议/意向。
- [ ] GitHub CI 使用真实依赖锁文件与构建命令；仓库远端指向协会授权仓库，不误推模板原始仓库。
